# pmos-playbook

The PMOS Playbook is the PM layer of [PMOS](https://github.com/brgn81/pmos-docs): skills, agents, rules and prompts for product management work, plus the PMOS types they work on. [PMOS](https://github.com/brgn81/pmos) installs it into a product workspace at a pinned ref.

Status: setup. Structure is in place; skills, agents and commands move here from `brgn81/pmos-legacy` step by step.

Checks: `uv run scripts/lint.py` and `pmos playbook validate .`. See [docs/authoring.md](docs/authoring.md).

Scope, architecture, decisions and roadmap live in [brgn81/pmos-docs](https://github.com/brgn81/pmos-docs/tree/main/docs). Instructions for working in this repo: [CLAUDE.md](CLAUDE.md).
